# Verilog Protocols – RTL Communication Design

A collection of **digital communication protocol implementations using Verilog HDL**.

This repository contains hands-on RTL designs for commonly used communication protocols, with a focus on understanding protocol operation, writing synthesizable RTL, and verifying designs through functional simulation.

---

## 🚀 Protocols Covered

### 🔹 UART
Universal Asynchronous Receiver/Transmitter

- UART Transmitter
- UART Receiver
- UART TX/RX Integration
- Baud Rate Generator
- Start and Stop Bit Handling
- Serial Data Transmission
- Functional Verification

### 🔹 SPI
Serial Peripheral Interface

- SPI Master
- SPI Slave
- SPI Master-Slave Communication
- Clock and Data Control
- Chip Select Handling
- Serial Data Transfer
- Functional Verification

### 🔹 I²C
Inter-Integrated Circuit

- I²C Master
- I²C Slave
- Start and Stop Conditions
- SDA and SCL Control
- Address Detection
- Read/Write Operations
- ACK/NACK Handling
- Functional Verification
